# ULTRA PARRY

A top-down parry duel against a bot. Hit the red ball back; every parry makes it faster and hit harder.

Play: https://cooltinpot.github.io/ultra-parry/ (open on your phone and use **Add to Home Screen** to install it as an app).

- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`: the installable app served by GitHub Pages.
- `source/`: the game source and `build.py`, which rebuilds the app files from it.
